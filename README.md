# Eyesite

> **🚧 Under Active Development** - Not ready for use yet. Check back soon!

## What is this?

An open-source observability platform for AI agents. Track every LLM interaction, optimize costs, and build better AI systems.

**Supports**: OpenAI, Anthropic, Google Gemini, and more.

## Status

This project is in **early alpha**. Core components are being built:

- ⏳ Backend services (Go)
- ⏳ Frontend dashboard (Next.js)
- ⏳ TypeScript SDK
- ⏳ Documentation

## Want to Contribute?

Switch to the **`develop`** branch to see active development:

```bash
git checkout develop
```

All documentation, tasks, and work-in-progress features are on `develop`.

## Updates

Follow development on the `develop` branch. `main` will only have tested, working features.
